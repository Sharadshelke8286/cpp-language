* C++ Basics
* Variables and Data Types
* Operators
* Conditional Statements
* Loops
* Functions
* Arrays
* Strings
* Pointers
* Structures
* Object-Oriented Programming (OOP)
* Classes and Objects
* Constructors and Destructors
* Inheritance
* Polymorphism
* Encapsulation
* Abstraction
* File Handling
* Exception Handling
* Basic Problem Solving

## ▶️ How to Run

Clone the repository:

```bash
git clone https://github.com/Sharadshelke8286/cpp-language.git
```

Move into the project folder:

```bash
cd cpp-language
```

Compile a C++ program:

```bash
g++ filename.cpp -o program
```

Run the program:

**Windows:**

```bash
program.exe
```

**Linux/macOS:**

```bash
./program
```
